# Engineering Protocol

1. Treat the live `/en` page as the sole visual reference. **CONFIRMED**
2. Re-verify any value marked **UNVERIFIED** using viewport screenshots and computed styles before implementation. **CONFIRMED**
3. Preserve asset identity and responsive crop behavior; do not replace public reference imagery with substitutes. **CONFIRMED**
4. Preserve accessible labels, required fields, privacy consent, keyboard-operable carousel controls, and external-link behavior. **CONFIRMED**
5. Implement only verified responsive rules; log newly measured values with date, viewport, and evidence source. **CONFIRMED**
6. Do not convert unknown values into estimates. **CONFIRMED**
7. Update `CHANGELOG.md` whenever a previously unverified item is confirmed. **CONFIRMED**
